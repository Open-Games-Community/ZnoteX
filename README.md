# ZnoteX Layouts

This repository contains the official and community layouts available for
**ZnoteX**.

Layouts published here are automatically listed inside the ZnoteX Admin Panel:

**Settings → Layouts → Browse Themes**

From there, administrators can browse available layouts, preview them, install
them directly, and receive updates when a newer version is published here.

---

## Browse Themes

ZnoteX reads the layout catalogue from this repository and displays the
available themes directly inside the Admin Panel.

Each layout can provide:

- Theme name
- Version
- Author
- Description
- Screenshot / preview
- Download package
- Details link

There is no need to manually download and extract themes when they are
available in the catalogue.

Simply open:

**Admin Panel → Settings → Layouts → Browse Themes**

and click **Install**.

---

## Layout Updates

Layouts are maintained and updated in this repository.

When a theme author publishes a newer version here, ZnoteX compares the version
available in the catalogue with the version currently installed on your site.

If a newer version is available, the **Install** button becomes **Update**.

This means layouts can be maintained independently from the main ZnoteX
repository without requiring a ZnoteX core update.

The repository contains the layout catalogue and the packages used by the
